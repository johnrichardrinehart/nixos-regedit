Filter

The filter matches option attribute paths, split on dots. Each query component must fuzzy-match a path component in order.

svc.ng.en can match services.nginx.enable. fs.name.type can match fileSystems.<name>.fsType.

Fetching

With Allow fetch unchecked, the evaluator runs offline and unlocked remote flakes are rejected before evaluation. Use a pinned flake URI with narHash, or enable Allow fetch.

With Allow fetch checked, the evaluator may resolve and fetch remote flakes. If an impure flake URI is resolved, the pinned evaluated URI is shown as read-only text and used for cache identity.

In the standalone page, browser CORS rules still apply. Sources whose archives are not CORS-readable from local pages, including GitHub codeload archives, need the Python backend app or a CORS-readable pinned source.

Input

The input accepts a flake URI whose flake exposes nixosModules, or a Nix expression returning the same shape as nixosModules.

An arbitrary expression should return one of these: a NixOS module, a list of NixOS modules, or an attrset whose values are NixOS modules.

Modules may be functions like { lib, pkgs, modulesPath, ... }: { options.example.enable = lib.mkEnableOption "example"; }, or attrsets with module keys such as imports, options, or config.

The expression itself can refer to pkgs, lib, and modulesPath. Module functions receive those through module arguments as well.

Standalone

The standalone page does not use an HTTP backend. Evaluation requires a compatible browser evaluator embedded as window.NixOSRegeditEvaluator.
