Filter

The filter matches option attribute paths, split on dots. Each query component must fuzzy-match a path component in order.

svc.ng.en can match services.nginx.enable. fs.name.type can match fileSystems.<name>.fsType.

Fetching

With Allow fetch unchecked, remote flake references are rejected before evaluation and the standalone fetch layer refuses browser HTTP requests. Local path flakes and expressions that do not fetch can still evaluate.

With Allow fetch checked, the evaluator may resolve and fetch remote flakes. If an impure flake URI is resolved, the pinned evaluated URI is shown as read-only text and used for cache identity.

In the standalone page, browser CORS rules still apply. Sources whose archives are not CORS-readable from local pages, including GitHub codeload archives, need the configured archive proxy, the Python backend app, or a CORS-readable pinned source. The default archive proxy is restricted to HTTPS archive URLs such as GitHub, GitLab, SourceHut, and common tar/zip archives, and it is rate-limited.

The standalone netrc field is optional and is used only for proxied archive fetches. It is never placed in the URL.

Input

The input accepts a flake URI whose flake exposes nixosModules, a flake URI with an explicit output selector such as github:owner/repo#foo, or a Nix expression returning the same shape.

Bare flake URIs default to #nixosModules.default. Explicit flake outputs and arbitrary expressions should return one of these: a NixOS module, a list of NixOS modules, or an attrset whose values are NixOS modules.

If a bare flake URI has no #nixosModules.default, the evaluator falls back to flake.lib.nixosSystem, flake.inputs.nixpkgs.lib.nixosSystem, then nixos/modules/module-list.nix. If the default output exists but cannot be evaluated as modules, evaluation fails instead of falling back.

Modules may be functions like { lib, pkgs, modulesPath, ... }: { options.example.enable = lib.mkEnableOption "example"; }, or attrsets with module keys such as imports, options, or config.

The expression itself can refer to pkgs, lib, and modulesPath. Module functions receive those through module arguments as well.

Standalone

The standalone page does not use an HTTP backend. Evaluation requires a compatible libeval-wasm integration embedded as window.NixOSRegeditEvaluator.
